# מתאים לי — סימולטור תנאי הסף

סימולטור שעונה על שאלות כלליות לגבי תנאי הסף לתוכנית המוסמך בעבודה סוציאלית
לבעלי תארים אחרים, בית הספר לעבודה סוציאלית ולרווחה חברתית, האוניברסיטה העברית.

פתוח לכל אדם. אין צורך בהרשמה או בהתחברות.

## מבנה

```
public/index.html              הדף. קובץ אחד, כולל הכל. אין בו מפתחות.
netlify/functions/claude.mjs   צד השרת. כאן נקרא המפתח וכאן יושב הפרומפט.
netlify.toml                   הגדרות הפריסה.
```

הדף מוגש כקובץ סטטי. בקשות ל-`/api/claude` מנותבות לפונקציה, לפי `config.path`
שבסוף קובץ הפונקציה.

## פריסה

1. העלו את התיקייה לריפוזיטורי ב-GitHub.
2. ב-Netlify: Add new project → Import an existing project → GitHub, ובחרו את
   הריפוזיטורי. את הגדרות הבנייה אין צורך למלא — הן נקראות מ-`netlify.toml`.
3. Project configuration → Environment variables, והוסיפו:
   - `ANTHROPIC_API_KEY` — המפתח מ-console.anthropic.com. סמנו כ-Secret.
   - `TURNSTILE_SECRET` — ה-Secret Key מהווידג'ט ב-Cloudflare Turnstile. Secret.
     בלי המשתנה הזה האימות מדולג והבוט ממשיך לעבוד.
   **המפתח לא נכנס לגיט ולא לקבצים. רק כאן.**
4. פרסו מחדש (Deploys → Trigger deploy), כי משתנים חדשים נכנסים לתוקף
   רק בפריסה הבאה.
5. ב-Cloudflare Turnstile, הוסיפו את כתובת ה-Netlify לרשימת ה-Domains של
   הווידג'ט. בלי זה כל אימות ייכשל.

## מפתח ה-Sitekey של Turnstile

ה-Sitekey הוא מפתח פומבי והוא צרוב בתוך `public/index.html`. אם מחליפים ווידג'ט,
מחפשים שם את `MSW_TURNSTILE_SITEKEY` ומעדכנים את הערך.

## הגנות

- המפתח נמצא רק בשרת ולעולם לא נשלח לדפדפן.
- הדפדפן שולח הודעות בלבד. הפרומפט, המודל ואורך התשובה נקבעים בשרת.
- פרטים מזהים (ת.ז, טלפון, דוא"ל חיצוני) נחסמים בדפדפן לפני השליחה, ושוב בשרת.
- בקשות ממקור שאינו ברשימה נדחות.
- הגבלת קצב של 20 בקשות לדקה לכתובת IP. המונה חי בזיכרון המופע, ולכן הוא
  מרסן שימוש אוטומטי אך אינו תקרה מוחלטת.
- **חובה**: תקרת הוצאה חודשית בחשבון ב-console.anthropic.com. זו ההגנה
  היחידה שקובעת תקרה לחיוב.

## עדכון תוכן

כל התוכן נמצא בראש `netlify/functions/claude.mjs`, במשתנה `KB`, מחולק לסעיפים
עם כותרת וקישור מקור. שינוי שם ודחיפה ל-GitHub מפעילים פריסה אוטומטית.

לשינוי בממשק עצמו יש לערוך את קובץ המקור `msw_admissions_bot.jsx` ולבנות ממנו
מחדש את `public/index.html`.
