# מנחה — בוט סיוע למועמדים

בוט שעונה על שאלות מועמדים לתוכנית המוסמך בעבודה סוציאלית לבעלי תארים אחרים,
בית הספר לעבודה סוציאלית ולרווחה חברתית, האוניברסיטה העברית בירושלים.

הבוט פתוח לכל אדם. אין צורך בהרשמה, בהתחברות או בחשבון כלשהו מצד המועמד.

## מבנה הפרויקט

```
public/index.html          הממשק. קובץ אחד, כולל הכל. אין בו מפתחות.
functions/api/claude.js    נתיב השרת. כאן נשמר המפתח וכאן יושב הפרומפט.
src/kb.js                  בסיס הידע ורשימת הקורסים. זה הקובץ לעדכון תוכן.
```

## פריסה ב-Cloudflare Pages

1. העלו את התיקייה לריפוזיטורי ב-GitHub.
2. ב-Cloudflare, פתחו Workers & Pages ובחרו Create → Pages → Connect to Git,
   ובחרו את הריפוזיטורי.
3. בהגדרות הבנייה: Build command ריק, Build output directory הוא `public`.
4. Settings → Environment variables: הוסיפו משתנה בשם `ANTHROPIC_API_KEY`
   עם המפתח מ-console.anthropic.com. סמנו אותו כ-Secret.
   **המפתח לא נכנס לגיט ולא לקבצים. רק כאן.**
5. פרסו. תקבלו כתובת בסגנון `https://msw-bot.pages.dev`.
6. פתחו את `functions/api/claude.js` ועדכנו את `ALLOWED_ORIGINS` לכתובת שקיבלתם
   וכן לכתובת הסופית באתר בית הספר.

לשילוב בתוך אתר בית הספר: `<iframe src="https://…" style="width:100%;height:800px;border:0"></iframe>`

## הגנות שכבר קיימות בקוד

- המפתח נמצא רק בשרת ולעולם לא נשלח לדפדפן.
- הדפדפן שולח הודעות בלבד. הפרומפט, המודל ואורך התשובה נקבעים בשרת,
  כדי שלא יהיה אפשר להשתמש בנתיב הזה כ-Claude חופשי.
- בקשות ממקור שאינו ברשימה נדחות.
- מגבלות על מספר ההודעות ועל אורכן.

## הגנות שכדאי להוסיף בממשק של Cloudflare

- Security → WAF → Rate limiting rules: הגבילו את `/api/claude`
  למשל ל-20 בקשות לדקה מאותה כתובת IP.
- ב-console.anthropic.com הגדירו תקרת הוצאה חודשית והתראה בדוא"ל.

## עדכון תוכן

כל התוכן נמצא ב-`src/kb.js`, מחולק לסעיפים עם כותרת וקישור מקור.
מעדכנים שם, שומרים ודוחפים ל-GitHub. Cloudflare בונה מחדש אוטומטית.
שימו לב: הפרומפט חוסם במכוון מסירת תאריכי הרשמה, כי הם משתנים משנה לשנה.
